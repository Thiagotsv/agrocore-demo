# AgroCore — demonstração

**▶ Assista: https://thiagotsv.github.io/agrocore-demo/**

O AgroCore junta a lavoura, o estoque, as máquinas e o financeiro de uma fazenda num lugar só, no computador e no celular, inclusive sem internet no campo.

Feito com Next.js 15, React, TypeScript, Supabase (PostgreSQL com segurança por linha), Leaflet com imagens de satélite, modo offline e testes com Playwright.

O código do AgroCore é privado; este repositório guarda só a página e o vídeo de demonstração.
